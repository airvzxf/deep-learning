# Deep Learning

Set of examples and experiments using Deep Learning.

## Tic Tac Toe

“src/tic-tac-toe/”

It is a deep learning model to learn who won or if it was a draw, given the list of the turns and movements of the game. The success rate is 99.8% of accuracy.

It has the “game-generator” folder that generates randomly games; it is useful to create the data that will be used to feed the training model.
